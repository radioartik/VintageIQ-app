# VintageIQ — Institutional Private Markets Operating System (v3.0)

VintageIQ is a high-fidelity, unified intelligence layer for **Family Offices**, **Individual High-Net-Worth Investors**, and **Private Investment Teams**. It streamlines the monitoring of complex, multi-asset portfolios including Private Equity, Venture Capital, Real Estate, and Direct Equities.

## ✨ Core Pillars
*   **Quiet Luxury Aesthetic**: A highly-refined, " institucional-grade" UI featuring a midnight navy/paper-white palette, glassmorphism, and sophisticated micro-animations.
*   **Multi-Asset Consolidation**: Unified views for PE/VC funds (with deterministic J-Curve modeling), public stocks (real-time performance), bonds, and alternative assets (art, real assets).
*   **Transaction-Driven Analytics**: A robust data engine where metrics like Paid-In, Distributions, and IRR are derived directly from a ledger source-of-truth.
*   **Vibe Coded Architecture**: Built using a modern Next.js 15+ stack with Tailwind CSS 4, Lucide icons, and Shadcn UI components.

## 🚀 Navigation Structure
- **Landing Page (`/`)**: A dynamic, engaging branding entry point explaining the product's value proposition for HNW ecosystem players.
- **Portfolio Dashboard (`/dashboard`)**: The primary analytics hub for oversight of Total AUM, IRR, TVPI, and allocation.
- **Exposure Analysis (`/exposure`)**: Deep-dive breakdowns across Geography, Sector, and Vintage Year.
- **Quarterly Report (`/report`)**: A print-ready, institutional-grade report generator for board-level presentations.

## 🛠️ Development & Deployment
First, install the dependencies:
```bash
npm install
```

Start the development portal:
```bash
npm run dev
```

The application is optimized for deployment on **Vercel**, leveraging internal API routes and server-side rendering for secure data handling.
